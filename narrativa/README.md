# Narrativa de VibeMap — para IAs y agentes

Este directorio existe para que cualquier IA (Claude, Codex, Gemini, etc.) que llegue a este repo entienda **rápido** de qué va el proyecto, sin tener que inferirlo del código.

Si eres una IA leyendo esto: empieza por `PROYECTO.md`. Si solo tienes 30 segundos, lee la sección "TL;DR" de ese archivo.

## Archivos

- [`PROYECTO.md`](./PROYECTO.md) — Qué es VibeMap, para quién, y por qué existe.
- [`ARQUITECTURA.md`](./ARQUITECTURA.md) — Cómo está construido (stack, flujo, endpoints).
- [`PROMPTS.md`](./PROMPTS.md) — Cómo le hablamos a Gemini y por qué.
- [`PRINCIPIOS.md`](./PRINCIPIOS.md) — Reglas de diseño que NO se rompen al iterar.
